# 网页组件规范

默认交付可复用的原生 Web Component。自绘 SVG 负责外形，模板负责眼神跟随和生命周期，无 CDN、框架或运行时网络请求。CursorTracker 只提供交互灵感；不把其仓库、全局变量、全局样式和阻止触摸事件的代码复制为组件依赖。

## SVG 眼部结构契约

每张 SVG 恰好两组 `data-peek-eye`，每组恰好一只眼白与一枚瞳孔，均为直接子级的 `ellipse`。其他物品结构不加这些标记。白色区域仍必须位于物品的合理纯黑暗部内。

```xml
<g data-peek-eye="" stroke="none" transform="rotate(-5 460 542)">
  <ellipse data-peek-white="" cx="460" cy="542" rx="21" ry="22" fill="#FFFFFF"/>
  <ellipse data-peek-pupil="" cx="460" cy="542" rx="8" ry="10" fill="#000000"/>
</g>
```

- 每只眼睛单独一组，倾斜写在组上；不要在眼白或瞳孔自身写 `transform`，模板需要它们共享同一局部坐标系。
- `cx/cy/rx/ry` 使用有限数值，半径为正。瞳孔占眼白长短轴的最大比例需小于 0.85，推荐约 0.35–0.5，以留出移动空间。
- 原图可以保留向左或向右看的瞳孔坐标；组件初始化时将其回正，再跟随指针。模板不改变原图文件。
- 模板会在每组内部添加眼睑容器，统一缩放眼白与瞳孔完成眨眼；不加眉毛、嘴或额外面部。
- 两眼根据共同注视方向移动，使用各自 `getScreenCTM().inverse()` 换算，兼容 SVG 视图框、响应式尺寸、组旋转和网页 CSS 变换。移动限制按瞳孔尺寸与眼白椭圆计算，不能仅用固定的网页像素偏移。

## 运行行为与嵌入边界

- 默认页面范围内跟随，平滑收敛后停止申请动画帧；无输入时不维持永久 RAF 循环。
- 使用 passive Pointer Events；不阻止默认触摸、滚动、缩放、点击与选择。
- shadow DOM 隔离样式；同页多个实例相互独立；不同物品使用不同标签名，避免重复注册。
- 响应 resize、包括嵌套容器在内的 scroll、视口交叉变化与文档可见性。不可见时停止动画、眨眼和闲置计时器。
- 移除元素时清理所有全局监听、observer、RAF 和 timeout；重新挂载后恢复，并避免重复创建眼睑。
- `prefers-reduced-motion: reduce` 时关闭平滑追赶、自动眨眼与闲置闭眼，保留直接注视。
- 无脚本环境仍可使用原图；交互必须把组件直接放进网页。`<img>` 内的 SVG 不会接收页面脚本；iframe 中也只能感知 iframe 内的指针。
- 默认标签是装饰性图形语义 `role="img"` 和可自定义的 `label`；不新增无意义的键盘焦点或强制接管焦点。

## 模板接口

`style="--peeking-size:240px"` 设置默认宽度，也可用正常 CSS 设置元素宽度。`label` 是读屏描述。`blink="off"` 禁用默认随机眨眼；`idle-ms="3500"` 可选启用闲置闭眼，默认不启用；`tracking="off"` 禁用跟随并回正。属性可在运行时更改。

用户明确要求 React/Vue/Svelte 等框架时，可以适配其项目入口与组件约定；保持同样的几何约束、样式隔离和卸载清理，并提供实际接入文件。默认用原生版本，不额外搭建完整应用或发布网站。

## 实际检查

生成的演示页故意包含两个尺寸的实例、页面滚动空间与普通按钮，以便检查跟随和页面共存。内置 `test_widget.mjs` 使用本地 Chrome DevTools Protocol 测试左右注视、极限位置下的瞳孔边界、旋转缩放、滚动与 resize、减少动态效果、关闭跟随、闲置唤醒、卸载重挂载、触摸滚动和按钮行为，并可保存截图。修改模板时运行这些检查；仅修改物品路径时仍需校验标记、看渲染并抽查跟随。
